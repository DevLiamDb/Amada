## Почему Amada

8 ноября 2026 года мы запустили **Jev 1.14** (закрытую модель принятия решений TypeSafe) и Amada на одних и тех же текстах, вопросах и вариантах ответа.

| | Jev 1.14 (платный API) | Amada 4.0 |
|---|:---:|:---:|
| Где работает | Серверы TypeSafe | **на вашем процессоре** |
| Цена | $0.042 за миллион токенов | **бесплатно** |
| Ваш текст покидает ваше устройство | да | **никогда** |
| Один короткий вопрос с ответом да / нет | ≈ 245 ms (включая интернет) | **≈ 40 ms** (×6 быстрее)* |
| Голосовой запрос, 60 намерений | **≈ 270 ms** | ≈ 390 ms |
| Prompt injection (116 сообщений) | 0.733 | **0.845** |
| Чтение, 11 языков (Belebele) | **0.947** | 0.554 |
| Открытые наборы данных, где модель лучше | **6 из 7** | 1 из 7 |

\* Медианное время на одном ноутбуке (Intel Core i5-11400H, 4 потока CPU, ONNX Runtime), измеренное с версией 4.0 12 ноября 2026 года: 41 ms для одной строки текста на экране, 54 ms для короткой заметки. Результат зависит от вашего процессора, длины текста и количества вариантов ответа: 60 вариантов занимают ~390 ms. Методика: [методология](https://amada.devliam.com/methodology.pdf).

Amada **не** лучше во всём: Jev намного точнее справляется с чтением на каждом языке и превосходит её на 6 из 7 открытых наборов данных. Amada выигрывает в скорости обработки коротких вопросов, цене, конфиденциальности и защите от prompt injection. Все результаты — и хорошие, и плохие — приведены на [странице сравнительного тестирования](https://amada.devliam.com/ru/benchmark).

## Для чего пригодится

- **Модерация:** «Это сообщение оскорбительное?», «Это prompt injection?» — до того, как оно попадёт в ваше приложение или LLM.
- **Сортировка:** распределяйте электронные письма, обращения или отзывы по нужным командам или категориям, получая вероятность для каждого варианта.
- **Проверка перед затратным этапом:** сначала задайте один недорогой вопрос с ответом да / нет, а большую модель вызывайте только при необходимости.
- **Тексты, требующие конфиденциальности:** заметки и сообщения, которые не должны покидать устройство.
- **Боты и игры:** бот Discord, игровой персонаж или система домашней автоматизации, реагирующая на ввод пользователей.
- **Маломощные устройства:** версии INT4 требуется около 1.2 GB ОЗУ при загрузке, а затем около 340 MB.

> ⚠️ Никогда не используйте Amada для принятия медицинских, юридических, финансовых решений, решений в сфере безопасности и других важных решений о реальных людях. Это экспериментальная модель, созданная одним человеком.

## PinkHouse: Amada как приложение для Windows

PinkHouse запускает Amada на вашем ПК без Python: окно для вопросов, локальный API для ваших скриптов (`http://127.0.0.1:8787`, с API-ключами) и менеджер моделей, который загружает версии Amada из этих релизов и проверяет каждую с помощью SHA-256.

Чтобы установить приложение, откройте **PowerShell** и вставьте:

```powershell
irm https://raw.githubusercontent.com/DevLiamDb/Amada/main/install.ps1 | iex
```

[Скрипт](install.ps1) загружает новейший файл `PinkHouse_Setup_<version>_x64.exe` из [релизов PinkHouse](https://github.com/DevLiamDb/Amada/releases?q=pinkhouse&expanded=true), проверяет его SHA-256 и запускает установщик. Права администратора не нужны. Вы также можете самостоятельно скачать установщик из [релиза PinkHouse 1.0.2](https://github.com/DevLiamDb/Amada/releases/tag/pinkhouse-v1.0.2).

> Windows 10 или 11, 64-разрядная версия (проверено на Windows 11). Установщик не содержит модели: при первом запуске выберите одну в разделе **MODELS** (Amada 4.0 INT4 — облегчённая версия, 188 MB). PinkHouse пока не работает на macOS или Linux.

PinkHouse бесплатна для любого использования, дома или на работе, но это приложение с закрытым исходным кодом: у него собственная лицензия, в отличие от моделей под лицензией MIT. Установщик попросит вас принять её. Ознакомьтесь с документами: [Лицензия](https://amada.devliam.com/ru/pinkhouse/license), [Условия использования](https://amada.devliam.com/ru/pinkhouse/terms), [Политика конфиденциальности](https://amada.devliam.com/ru/pinkhouse/privacy) и [Юридическое уведомление](https://amada.devliam.com/ru/pinkhouse/legal-notice). Кратко: телеметрии нет, ваши тексты остаются на вашем ПК, а приложение подключается к интернету только для загрузки моделей из этих релизов.

## Установка

> Требования: **Python 3** и **pip**.

```bash
git clone https://github.com/DevLiamDb/Amada.git
cd Amada
pip install -r requirements.txt
```

Затем скачайте модель:

1. Скачайте `amada-4.0.zip` из [последнего релиза](https://github.com/DevLiamDb/Amada/releases/latest) (или меньший архив `amada-4.0-int4.zip`, 188 MB, из того же релиза).
2. Распакуйте его в папку `Release/` рядом с `play.py`, чтобы получить `Release/amada-4.0/amada_model.onnx` и `Release/amada-4.0/tokenizer/`.

> ⚠️ **Храните папку `tokenizer/` рядом с `amada_model.onnx`.** Без неё ответы будут неправильными.

## Использование

### 1. В терминале

```bash
python play.py
```

Вставьте текст, нажмите Enter на пустой строке, затем задайте вопросы:

```text
Did Lea eat an apple?                          -> yes / no
Which apple did she eat? | red, green, yellow  -> choice
How hungry is she? #                           -> score (none / low / moderate / high)
How happy is she? # not at all, a bit, very    -> score with your own levels
:new = new text    :q = quit
```

Другие версии: `python play.py --version 4.0-int4` (требуется onnxruntime 1.20+), `python play.py --version 3.1`, `python play.py --version 2.0`...

### 2. Из Python

```python
from play import Amada, release_model

amada = Amada(release_model("4.0"))
answers, cut = amada.ask(
    "BOOM. Three knocks on my door. Then nothing.",
    [{"type": "noul", "text": "Is it my mother knocking?"},
     {"type": "score", "text": "How scary is it?", "levels": ["none", "low", "moderate", "high"]}],
)
print(answers)   # [{'p_yes': ..., 'p_unknown': ...}, {'probs': {'none': ..., ...}}]
```

### 3. Три типа вопросов

| Тип | Вы спрашиваете | Amada возвращает |
|---|---|---|
| **да / нет** (`noul`) | `Did the customer pay by card?` | вероятность ответа «да», а также вероятность того, что **в тексте этого не сказано** |
| **вариант** | `What does the customer want? \| a refund, an exchange, ...` | по одной вероятности на каждый вариант, в сумме 100 % |
| **оценка** | `How urgent is it? #` | по одной вероятности на каждый уровень (none, low, moderate, high или заданные вами уровни) |

Amada знает только текст, который вы ей передали. Без интернета, памяти и генерации текста.

**4.0 INT4** протестирована 12 ноября 2026 года на точно тех же примерах, что и 4.0 (на CPU вместо GPU). **Скорость** (медианное время одного ответа, один запрос за раз, одни и те же запросы для всех моделей · Amada на Intel Core i5-11400H, 4 ядра CPU · Jev через API из Франции). 4.0 и 4.0 INT4 измерены 12 ноября 2026 года, Jev — 8 ноября:

| Запрос | Amada 4.0 | Amada 4.0 INT4 | Jev 1.14 |
|---|:---:|:---:|:---:|
| Одна строка экранного текста, да / нет | 41 ms | **37 ms** | 244 ms |
| Краткая заметка, да / нет | 54 ms | **49 ms** | 247 ms |
| Отрывок для чтения, 4 ответа | 161 ms | 159 ms | 264 ms |
| Голосовой запрос, 60 намерений | 390 ms | 375 ms | **270 ms** |

В том же запуске, что и INT4, 4.0 показала 40, 55, 154 и 388 ms: INT4 примерно такая же быстрая (чуть быстрее на коротких вопросах, чуть медленнее при чтении). Основная экономия — память: около 340 MB RAM после загрузки вместо 1.4 GB.

**Слабые места**, намеренно обозначенные: TREC (тип ожидаемого ответа, 0.52 у 4.0 против 0.39 ранее), Banking77 (0.59, на 2.5 пункта ниже 3.1), порядковые оценки (около 76 %) и очень длинные тексты. Небрежное письмо теперь почти не влияет на результат: отложенные вопросы с опечатками — 0.960 на английском и 0.967 на 11 языках.

> **Честное замечание:** в наших коротких тестах используются ответы сильного ИИ (GPT-6 Luna), а не человеческих аннотаторов; тексты в них похожи на обучающие данные. В открытых датасетах используются человеческие метки.

<details>
<summary><b>⚙️ Как это устроено</b></summary>
<br>

```
text + questions ──► tokenizer ──► encoder (mmBERT-base, ONNX, CPU) ──► one head per question type
                                                                     │
                                                                     └── temperatures ──► calibrated probabilities
```

- **Один проход для всех вопросов:** текст и каждый вопрос обрабатываются вместе. Каждый вопрос начинается с маркера `[Q]`, каждый вариант — с `[OPT]`, каждый уровень — с `[LVL]`.
- **Три типа ответов:** да / нет (с вариантом «в тексте не сказано»), выбор (одна оценка на вариант, в сумме 100 %), оценка (одна вероятность на уровень).
- **Калибровка:** начиная с 3.0.1 температуры зависят от длины текста и количества вариантов. Поэтому «95 %» от Amada означает примерно 95 %.
- **Время растёт с количеством вариантов:** обрабатывается каждый вариант. Два варианта занимают ~40 ms, 77 вариантов — ~720 ms.

</details>

Да, и вы также можете распространять или продавать свою дообученную версию. Сохраняйте вместе с ней уведомление MIT (и NOTICE.md).

**Какую версию использовать?**
4.0 подходит для большинства задач. 4.0 INT4 — если вам нужна небольшая загрузка или мало оперативной памяти (примерно на 1 пункт ниже в некоторых задачах классификации), а 3.1 — если ваша задача похожа на Banking77 или определение эмоций. Старые версии доступны для сравнения.

**Сколько вариантов ответа может быть в вопросе с выбором?**
Два или больше, ограничений сверху нет: текст, вопрос и варианты ответа вместе должны укладываться в 8,192 токена. Модели 3.0 и новее обучались на списках размером до 386 вариантов.

**Какое оборудование нужно?**
Обычный CPU. Загрузка занимает около 9 секунд, после загрузки требуется около 1.4 GB оперативной памяти (FP32); не более 1.2 GB с INT4. GPU не нужен, интернет после загрузки не нужен.

**Есть ли API или размещённая версия?**
Нет. Amada работает на вашем компьютере.

**Ответы кажутся неправильными.**
Убедитесь, что папка `tokenizer/` находится рядом с файлом `amada_model.onnx`.

</details>
